# 🧙‍♂️ Projet Poudlard 

---------------------------------------------------------------------

## 🎯 Objectifs du projet

Ce projet a pour but de mettre en pratique les notions fondamentales de Python :

- Fonctions et modularisation
- Dictionnaires, listes et structures imbriquées
- Conditions et boucles
- Gestion de l’aléatoire (random)
- Lecture de fichiers JSON (json)
- Organisation d’un projet Python structuré
- Travail collaboratif avec Git et GitHub

---------------------------------------------------------------------

## 🧩 Principe du jeu

Le joueur progresse à travers plusieurs chapitres scénarisés :

Chapitre 1 – L’arrivée dans le monde magique
- Création du personnage
- Réception de la lettre de Poudlard
- Rencontre avec Hagrid
- Achats sur le Chemin de Traverse

Chapitre 2 – Le voyage vers Poudlard
- Rencontres avec Ron, Hermione et Drago
- Cérémonie de répartition dans une maison
- Installation dans la salle commune

Chapitre 3 – Les cours et la magie
- Apprentissage de sorts
- Quiz de magie pour gagner des points de maison

Chapitre 4 – La grande conclusion
- Match de Quidditch

---------------------------------------------------------------------

## ▶️ Lancer le jeu

Prérequis :
- Python 3.x
- Aucune bibliothèque externe requise

Commande de lancement :
python main.py

---------------------------------------------------------------------

## 📁 Données JSON

Les fichiers du dossier data/ contiennent toutes les données externes du jeu :

- maisons.json : informations sur les maisons
- inventaire.json : objets et prix du Chemin de Traverse
- sorts.json : sorts et catégories
- quiz_magie.json : questions et réponses du quiz
- equipes_quidditch.json : équipes de Quidditch
